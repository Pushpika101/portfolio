AI · IOT · EMBEDDED SYSTEMS

One connected safety system.
Three parts working together.

PathFinder combines a guardian mobile app, a project website, and a wearable navigation prototype for people with visual impairments.

01
GUARDIAN MOBILE APP

Remote support, wherever it matters.

WHAT GUARDIANS CAN DO

See the essential information at a glance.

The app keeps device safety tools close without overwhelming the guardian.

  • Live GPS tracking
  • Battery & device status
  • SOS notifications
  • Safe-zone monitoring
  • Remote live feed
02
PROJECT WEBSITE

The story, system, and validation.

OVERVIEW

A clear introduction to the problem and solution.

DOCUMENTATION

Capabilities and engineering decisions in one place.

The site explains the device, connected experiences, architecture, and project validation.

03
PHYSICAL PROTOTYPE

Computer vision made wearable.

THE DEVICE

Portable guidance built around real-world movement.

A Raspberry Pi, camera, GPS, audio output, and physical controls work together inside a wearable enclosure.

DIRECT CONTROLS

Important actions stay tactile.

  • Obstacle guidance
  • Road-crossing support
  • One-button SOS
  • Audio feedback
HOW IT CONNECTS

From surroundings to support.

  1. 01SenseCamera, GPS & controls
  2. 02ProcessRaspberry Pi & YOLO
  3. 03ConnectFirebase & WebRTC
  4. 04SupportMobile & web apps
THE TOOLKIT

Built across hardware, AI, and cloud.

  • Python
  • Raspberry Pi
  • YOLOv8
  • OpenCV
  • Firebase
  • JavaScript
THE RESULT

One integrated prototype.

On-device perception, accessible audio guidance, emergency tools, and remote guardian support inside a portable system.

Functional prototypeTeam engineering projectUniversity of Peradeniya

PathFinder is an experimental assistive prototype. Road-crossing feedback does not guarantee a safe crossing or replace established mobility aids.

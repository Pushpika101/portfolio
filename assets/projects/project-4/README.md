# Project 4 images

Add this project’s JPG, JPEG, PNG, WebP, AVIF, or SVG images directly here.
Use names such as `01-overview.webp`, `02-dashboard.webp`, and `03-mobile.webp` to control gallery order.

Run `npm run build` and refresh the site. Images are automatically added to Project 4’s flowing gallery. Empty folders keep the existing placeholder artwork.
